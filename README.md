# Тополево · Зелёная, 25

Интерактивная воксельная 3D-сцена на **Three.js** (`0.160.0`): дом и участок по адресу Тополево, ул. Зелёная, 25.

## Возможности
- **4 времени года:** Весна (цветение и лепестки), Лето (зелень и тополиный пух), Осень (листопад), Зима (снег и голые ветки).
- **Режим «Вечер»:** переключение освещения на вечерний/ночной режим.
- **Управление камерой:** вращение левой кнопкой мыши, приближение колесом, сдвиг правой кнопкой, автоматическое вращение и переключение осадков/листопада.

## Как запустить локально
Откройте `index.html` в браузере или поднимите локальный HTTP-сервер в папке проекта:

```bash
python3 -m http.server 8080
```

После этого откройте в браузере: `http://localhost:8080`
